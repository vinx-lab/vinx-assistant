# 0003 网页密码

## 背景

第一期的网页不设密码，安全全靠部署环境的网络边界。挂到反向代理后面以后，同一网络里能访问代理的设备都能看到全部条目，还能改设置。准备开源后，别人部署时也需要一道最基本的门。

## 要做的

- **单一密码**：只有一个用户，所以只要密码，不要用户名。
- **首次设置**：
  - 没设密码时网页照常可用，每页顶部提示「还没设密码」，并给出设置入口。
  - 在「设置 → 账号与数据 → 密码」里设置；设置成功后，当前浏览器直接处于登录状态。
- **修改**：要先输入当前密码。改完后其他设备的登录全部失效，当前设备保持登录。
- **忘记密码**：在服务器上运行 `vinx-assistant password`，输入两次新密码即可重置，同时让所有登录失效。也可以用 `--clear` 清除密码，恢复成无密码状态。
- **登录**：
  - 设了密码后，访问任何页面都先跳到登录页，登录后回到原来的地址。
  - 登录状态保持 30 天。「退出」只退出当前设备；设置页另有「退出所有设备」。
  - 登录页的地址是 `/signin`。`/login` 已经用于微信扫码，不改动。
- **不需要登录的路径**：`/signin`、`/static/`、`/healthz`。
- **前端脚本请求**：未登录时返回 401，不做跳转。
- **存储**：
  - 密码用 PBKDF2-SHA256 加随机盐保存，用标准库，不加新依赖。比较时用常数时间。
  - 登录会话存在数据库里，只保存令牌的哈希值。
  - cookie 设为 `HttpOnly`、`SameSite=Lax`，`Path` 等于 base path（没有设置时为 `/`）。经 HTTPS 访问时加 `Secure`。
- **防暴力破解**：15 分钟内累计失败 10 次后锁定 15 分钟，锁定期间登录页显示剩余时间，日志记录一条 WARN。锁定后也可以用命令行重置。
- **兼容**：没设密码时行为和现在完全一样，现有部署升级后不受影响。

## 不做

- 多用户、角色。
- 两步验证。
- 「记住我」开关：一律保持 30 天。

## 验证

- 单元测试：
  - 哈希与校验。
  - 会话创建、过期、吊销。
  - 锁定计数。
  - cookie 属性（含 base path 和 HTTPS 两种情况）。
- 网页测试：
  - 未设密码时可以访问，且能看到提示。
  - 设密码后未登录时跳到 `/signin`；前端脚本请求返回 401；`/static`、`/healthz` 不受影响。
  - 登录后回到原地址，`next` 参数不能被用来跳到外部网站。
  - 改密码后旧会话失效。
  - 退出。
  - 跨站提交登录表单被拒。
  - 带 base path 的情况。
- 命令行：`password` 能设置和清除密码。
- 真实验收：用手机和电脑浏览器经反向代理登录、退出。

## 结果

2026-10-01 完成实现，真实验收未做。

- 密码记录存在 settings 表的 `auth` 键：PBKDF2-SHA256、60 万次迭代、16 字节随机盐，常数时间比较。会话存在新表 `web_sessions`（迁移 0005），只存令牌的 sha256，固定 30 天到期，过期的在查询和新建会话时清理。
- cookie `vinx_session`：`HttpOnly`、`SameSite=Lax`、`Path` 等于 base path。直接 TLS，或者回环地址上的反向代理发来 `X-Forwarded-Proto: https` 时加 `Secure`；别的来源发来的这个头不信任。
- 登录检查排在 Host 白名单和跨站防护之后。未登录时，页面 303 到 `/signin?next=…`，表单 POST 303 到 `/signin`，前端脚本接口（拉取模型列表、扫码状态）和扫码二维码图片返回 401。`next` 和 `back` 共用同一套站内地址校验，这次还加上了拒绝控制字符。
- 失败计数全站共用、只在内存里。密码记录变化时（网页修改或命令行重置）自动清零，所以被锁定后用命令行重置能立即解锁。进入锁定时记一条 WARN，日志里不含密码。
- 每个请求都从数据库读密码记录和会话，不做缓存，命令行的改动立即生效。
- 命令行 `vinx-assistant password`：终端上用 `stty -echo` 关闭回显，输入两次；标准输入不是终端时逐行读两次；`--stdin` 只读一行、不确认；`--clear` 清除密码。这几种方式都会吊销全部会话。
- 验证：单元测试和网页测试覆盖了「验证」一节列出的各项（含 base path、跨站提交登录表单、锁定与解锁、命令行改动即时生效），`make vet`、`make test` 通过；用伪终端手动跑过一次交互输入，确认密码不回显。
- 未验证：用手机和电脑浏览器经反向代理登录、退出的真实验收；页面样式没有在真实浏览器里看过。
